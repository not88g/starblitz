
# 🌌 STARBLITZ

**A retro-style space shooter made in PICO-8**  
Stable Release — **v1.0**  
_by 88g_

---

## 🎮 Description

**STARBLITZ** is a fast-paced pixel space shooter made in fantasy console PICO-8.  
Pilot your starship, blast through waves of enemies, defeat bosses, and survive as long as you can.  
Reach **9999 points** to unlock the ending screen!

---

## 🕹️ Controls

- **Move**: Arrow keys or **WASD** (
- **Shoot**: Z / X or **Left Mouse Button**
- **Retry**: Z (on Game Over screen)

---

## ✨ Features

- Sprite-based graphics for player, enemies, bullets
- Bosses every 25 points
- Increasing difficulty every 10 points
- Power-ups: Extra life every 15 points
- Game Over and Victory screens
- Smooth bullet animations
- Title screen with version & snowflake detail ❄️

---

## 📦 Versions

- **Debut/v1.1**: Simple prototype with boxes and basic shooting
- **Beta v1.3–v2.3**: Many features added, bugs fixed, polish applied
- **Stable v1.0**: Final version with full gameplay loop and visual polish
